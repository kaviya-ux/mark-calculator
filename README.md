# Mark Calculator

A simple **Mark Calculator** web application that calculates a student's total marks, average, and grade based on the entered subject marks.

## Features

* Enter marks for multiple subjects
* Calculate total marks
* Calculate average percentage
* Display the student's grade
* Simple and user-friendly interface
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript
* Tailwind CSS
* 
## How It Works

1. Enter the student's marks for each subject.
2. Click the **Calculate** button.
3. The application calculates:
   * Total Marks
   * Average
   * Grade
4. The result is displayed on the screen.
   
## Purpose

This project was created to practice **HTML, CSS, Tailwind CSS, and JavaScript** concepts such as form handling, calculations, DOM manipulation, and conditional statements.
